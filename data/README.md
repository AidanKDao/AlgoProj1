# Sample Data

All files here are generated by `data/scripts/generate_data.py`. Edit the script and re-run it
rather than hand-editing files, so the CSV and JSON copies stay identical.

The generated folders (`scale/`, `scenarios/`) are gitignored, so **run this once after cloning**
(and again after pulling changes to the script):

```
python data/scripts/generate_data.py
```

All data is simulated.

## Layout

Every dataset folder contains the same six files:
`donations.{csv,json}`, `recipients.{csv,json}`, `volunteers.{csv,json}`.

### `scale/` — randomized, seeded (seed 335)

| Dataset | Donations | Recipients | Volunteers | Use for |
|---|---|---|---|---|
| `tiny` | 8 | 3 | 3 | Reading output by hand, debugging |
| `small` | 25 | 6 | 6 | Demo / presentation |
| `medium` | 100 | 20 | 15 | Metrics and FIFO-vs-greedy comparison |
| `large` | 1,000 | 120 | 90 | Contention under load |
| `xlarge` | 10,000 | 1,000 | 700 | Timing runs for the complexity discussion |

### `scenarios/` — hand-built edge cases (one per required test)

| Scenario | Expected behavior |
|---|---|
| `normal_match` | D-1001 is assigned to R-201 with V-301 |
| `duplicate_ids` | Second D-1001, R-201, and V-301 records are flagged by validation |
| `expired_donation` | D-1001 is already expired; D-1002 has 10 minutes left; D-1003 is assigned |
| `no_compatible_food_type` | No recipient accepts dairy → unassigned |
| `insufficient_recipient_capacity` | 150 units, largest recipient holds 100 → unassigned |
| `no_volunteer_capacity` | 90 units, largest vehicle holds 60 → unassigned |
| `competing_capacity` | Two 40-unit donations, recipient holds 50 → only one assigned |
| `fifo_vs_greedy_differ` | FIFO assigns 1 donation, greedy assigns 2 (explained in the script) |
| `starvation` | Canned goods (D-1001) arrive first but keep getting deferred by urgent meals under greedy |
| `empty` | Header-only CSVs and `[]` JSON files |

## Format

- **Times** are integer minutes since the start of the simulation (0 = 8:00 AM, 720 = 8:00 PM).
- **`arrival_order` is not stored in the files.** The loader should assign it from row order
  (`enumerate(rows)`); JSON arrays keep their order.
- **`accepted_food_types`** is a JSON array, or a semicolon-separated cell in CSV
  (`dairy;produce`). The loader should turn both into a `set[str]`.
- **CSV values are all strings**; the loader must convert the numeric fields to `int`.

Food types: `prepared_meals`, `produce`, `bakery`, `dairy`, `frozen`, `canned_goods`
Areas: `north`, `south`, `east`, `west`, `central`

### Fields

| File | Fields |
|---|---|
| donations | `donation_id`, `donor_name`, `food_type`, `quantity`, `ready_time`, `expiry_time`, `pickup_area` |
| recipients | `recipient_id`, `organization_name`, `accepted_food_types`, `capacity`, `closing_time`, `dropoff_area` |
| volunteers | `volunteer_id`, `vehicle_capacity`, `maximum_pickups`, `availability_start`, `availability_end`, `pickup_area` |
